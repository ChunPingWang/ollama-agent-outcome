# Spec 001 — 個人資料管理

## 背景
系統需要為使用者提供管理個人資料的功能，包括建立新的個人資料、查詢現有資料、更新個人資訊以及刪除不再需要的資料。此功能需確保資料的完整性與一致性，並提供清晰的錯誤回饋。

## 名詞
- **個人資料 (Profile)**：代表一個使用者的基本資訊集合，包含唯一識別碼、姓名、電子郵件地址與備註。
- **電子郵件 (Email)**：用於識別使用者的唯一字串，需符合標準電子郵件格式。
- **識別碼 (ID)**：系統自動產生的唯一識別字，用於標識每一筆個人資料。

## 使用者情境

### US-1 建立個人資料
身為系統使用者，我想要建立一筆新的個人資料，以便在系統中註冊我的基本資訊。

### US-2 查詢個人資料
身為系統使用者，我想要透過識別碼查詢特定的個人資料，以便確認資料內容或進行後續操作。

### US-3 更新個人資料
身為系統使用者，我想要更新已有的個人資料，以便修正錯誤或更新現況。

### US-4 刪除個人資料
身為系統使用者，我想要刪除特定的個人資料，以便移除不再需要的資料。

## 驗收條件

```gherkin
功能: 個人資料 CRUD 操作
    作為系統使用者
    我想要管理個人資料
    以便維護我的基本資訊

    場景: 成功建立個人資料
        當 我發送 POST 請求至 "/profiles"
        並且 請求內文包含有效的姓名、電子郵件與備註
        那麼 回應狀態碼應為 201 Created
        並且 回應標頭包含 "Location" 指向新建立的資源
        並且 回應內文包含新建立的個人資料識別碼

    場景: 建立個人資料時電子郵件格式錯誤
        當 我發送 POST 請求至 "/profiles"
        並且 請求內文包含無效的電子郵件格式
        那麼 回應狀態碼應為 400 Bad Request
        並且 回應內文包含錯誤訊息

    場景: 建立個人資料時電子郵件已存在
        假設 系統中已存在電子郵件為 "test@example.com" 的個人資料
        當 我發送 POST 請求至 "/profiles"
        並且 請求內文包含電子郵件 "test@example.com"
        那麼 回應狀態碼應為 409 Conflict
        並且 回應內文指出電子郵件重複

    場景: 成功查詢個人資料
        假設 系統中存在識別碼為 "uuid-123" 的個人資料
        當 我發送 GET 請求至 "/profiles/{id}"
        其中 {id} 為 "uuid-123"
        那麼 回應狀態碼應為 200 OK
        並且 回應內文包含該個人資料的詳細資訊

    場景: 查詢不存在的個人資料
        當 我發送 GET 請求至 "/profiles/{id}"
        其中 {id} 為不存在的識別碼
        那麼 回應狀態碼應為 404 Not Found
        並且 回應內文指出資料不存在

    場景: 成功更新個人資料
        假設 系統中存在識別碼為 "uuid-123" 的個人資料
        當 我發送 PUT 請求至 "/profiles/{id}"
        其中 {id} 為 "uuid-123"
        並且 請求內文包含更新後的姓名、電子郵件與備註
        那麼 回應狀態碼應為 200 OK
        並且 回應內文包含更新後的個人資料

    場景: 更新不存在的個人資料
        當 我發送 PUT 請求至 "/profiles/{id}"
        其中 {id} 為不存在的識別碼
        那麼 回應狀態碼應為 404 Not Found

    場景: 成功刪除個人資料
        假設 系統中存在識別碼為 "uuid-123" 的個人資料
        當 我發送 DELETE 請求至 "/profiles/{id}"
        其中 {id} 為 "uuid-123"
        那麼 回應狀態碼應為 204 No Content
        並且 該識別碼的資料隨後無法被查詢到

    場景: 刪除不存在的個人資料
        當 我發送 DELETE 請求至 "/profiles/{id}"
        其中 {id} 為不存在的識別碼
        那麼 回應狀態碼應為 404 Not Found
```

## API 概要

| HTTP 方法 | 路徑 | 描述 | 成功狀態碼 | 失敗狀態碼 |
| :--- | :--- | :--- | :--- | :--- |
| POST | `/profiles` | 建立新個人資料 | 201 Created | 400 Bad Request, 409 Conflict |
| GET | `/profiles/{id}` | 查詢單一個人資料 | 200 OK | 404 Not Found |
| PUT | `/profiles/{id}` | 更新單一個人資料 | 200 OK | 400 Bad Request, 404 Not Found |
| DELETE | `/profiles/{id}` | 刪除單一個人資料 | 204 No Content | 404 Not Found |
